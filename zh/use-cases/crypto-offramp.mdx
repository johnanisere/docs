---
title: "即时加密出金"
description: "将加密货币即时转换为现金。"
---

## 场景

用户希望出售加密货币，并通过单一简化流程在银行账户中收到现金。现有 non-named offramp 行为保持不变。

## 工作流程

### 1. 添加受益人银行账户

首先，将目标银行账户添加为受益人。收到加密货币后，资金将发送到该账户。

```bash
curl --request POST \
  --url https://api.bullring.finance/v1/ramp/{subaccountId}/banking/beneficiaries \
  --header 'Content-Type: application/json' \
  --header 'x-api-key: YOUR_API_KEY' \
  --data '{
    "account_id": "667.136.083-96",
    "account_type": "cpf",
    "currency": "BRL"
  }'
```

### 2. 发起加密出金

通过指定收款人和目标货币金额来发起出金。

```bash
curl --request POST \
  --url https://api.bullring.finance/v1/ramp/{subaccountId}/banking/offramp/initiate \
  --header 'Content-Type: application/json' \
  --header 'x-api-key: YOUR_API_KEY' \
  --data '{
    "recipient_id": "343bb162-d0ae-46ef-a5bb-13505eb52c89",
    "amount": 88
  }'
```

### 3. USD Offramp 和 named withdrawal

**端点：** `POST /v2/ramp/{subaccountId}/banking/offramp/initiate`

对于 USD offramps，`to` 对象可以包含 `payment_rail`，取值为 `RTP`、`WIRE`、`SWIFT`、`SAME_DAY_ACH` 或 `ACH`。仅对 USD named withdrawal 将 `named_withdrawal` 设置为 `true`。named withdrawal 目前仅支持 USD offramps，要求使用通过 `business_name` 识别的企业收款人，并要求该收款人包含 `beneficiary_date_of_formation`、`beneficiary_country_of_formation` 和 `beneficiary_national_identification_number`。named withdrawal 仅支持 `WIRE` 和 `SWIFT`；`RTP`、`SAME_DAY_ACH` 和 `ACH` 仍仅在适用时支持 non-named USD 流程。

如需在发起前获取报价，请在报价端点 (`POST /v2/ramp/{subaccountId}/banking/offramp/quote`) 使用相同的 `to.payment_rail` 和 `to.named_withdrawal` 字段。

### 示例：普通 Non-named USD Offramp

```bash
curl --request POST \
  --url https://api.bullring.finance/v2/ramp/{subaccountId}/banking/offramp/initiate \
  --header 'Content-Type: application/json' \
  --header 'x-api-key: YOUR_API_KEY' \
  --data '{
    "from": {
      "chain": "ETH-SEPOLIA",
      "asset": "USDC",
      "amount": 100,
      "sender_address": "0x742d35Cc6634C0532925a3b844Bc454e4438f44e"
    },
    "to": {
      "recipient_id": "39e4f180-b558-4346-bf5f-2ec9c6b444f4",
      "currency": "USD",
      "payment_rail": "ACH"
    },
    "client_offramp_reference": "5a26b319-fc68-4ee2-83f2-19889571619d"
  }'
```

  --url https://api.bullring.finance/v2/ramp/{subaccountId}/banking/offramp/quote \

## 状态和 Webhook

使用 `GET /v2/ramp/{subaccountId}/banking/offramp/{offrampId}` 跟踪 offramp 状态，并使用提款 webhook 事件跟踪最终支付状态。
