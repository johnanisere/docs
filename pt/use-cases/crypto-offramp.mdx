title: "Off-Ramp Cripto Instantâneo"
description: "Converta cripto em dinheiro instantaneamente."
---

## Cenário

Um usuário deseja vender cripto e receber dinheiro em sua conta bancária usando um fluxo único e simplificado. O comportamento existente de offramps non-named não mudou.

## Fluxo de Trabalho

### 1. Adicionar Conta Bancária de Beneficiário

Primeiro, adicione a conta bancária de destino como beneficiário. É para lá que os fundos serão enviados após o recebimento da cripto.

```bash
curl --request POST \
  --url https://api.bullring.finance/v1/ramp/{subaccountId}/banking/beneficiaries \
  --header 'Content-Type: application/json' \
  --header 'x-api-key: YOUR_API_KEY' \
  --data '{
    "account_id": "667.136.083-96",
    "account_type": "cpf",
    "currency": "BRL"
  }'
```

### 2. Iniciar Offramp Cripto

Inicie o offramp especificando o destinatário e o valor na moeda de destino.

```bash
curl --request POST \
  --url https://api.bullring.finance/v1/ramp/{subaccountId}/banking/offramp/initiate \
  --header 'Content-Type: application/json' \
  --header 'x-api-key: YOUR_API_KEY' \
  --data '{
    "recipient_id": "343bb162-d0ae-46ef-a5bb-13505eb52c89",
    "amount": 88
  }'
```

### 3. Offramps USD e named withdrawal

**Endpoint:** `POST /v2/ramp/{subaccountId}/banking/offramp/initiate`

Para offramps USD, o objeto `to` pode incluir `payment_rail` com `RTP`, `WIRE`, `SWIFT`, `SAME_DAY_ACH` ou `ACH`. Defina `named_withdrawal` como `true` apenas para USD named withdrawal. named withdrawal atualmente suporta apenas offramps USD, exige destinatário empresarial identificado por `business_name` e exige que o destinatário inclua `beneficiary_date_of_formation`, `beneficiary_country_of_formation` e `beneficiary_national_identification_number`. named withdrawal suporta apenas `WIRE` e `SWIFT`; `RTP`, `SAME_DAY_ACH` e `ACH` continuam suportados apenas para fluxos USD non-named quando aplicável.

Use o endpoint de cotação (`POST /v2/ramp/{subaccountId}/banking/offramp/quote`) com os mesmos campos `to.payment_rail` e `to.named_withdrawal` quando precisar de preço antes de iniciar o offramp.

### Exemplo: Offramp USD Non-named Normal

```bash
curl --request POST \
  --url https://api.bullring.finance/v2/ramp/{subaccountId}/banking/offramp/initiate \
  --header 'Content-Type: application/json' \
  --header 'x-api-key: YOUR_API_KEY' \
  --data '{
    "from": {
      "chain": "ETH-SEPOLIA",
      "asset": "USDC",
      "amount": 100,
      "sender_address": "0x742d35Cc6634C0532925a3b844Bc454e4438f44e"
    },
    "to": {
      "recipient_id": "39e4f180-b558-4346-bf5f-2ec9c6b444f4",
      "currency": "USD",
      "payment_rail": "ACH"
    },
    "client_offramp_reference": "5a26b319-fc68-4ee2-83f2-19889571619d"
  }'
```

```bash

  --url https://api.bullring.finance/v2/ramp/{subaccountId}/banking/offramp/quote \

  --header 'x-api-key: YOUR_API_KEY' \

  }'
```

## Status e Webhooks

Acompanhe o status do offramp com `GET /v2/ramp/{subaccountId}/banking/offramp/{offrampId}` e use eventos de webhook de saque para acompanhar o pagamento final.
